# 🏦 Bandhan Bank – End-to-End Business Intelligence Analytics

## 📌 Project Overview

An end-to-end Business Intelligence solution developed to analyze banking customer, loan, payment, and repayment data.

The project demonstrates the complete data analytics lifecycle using SQL Server, SSIS, Data Warehousing, and Power BI — from data extraction and transformation to business reporting and insights.

## 🛠️ Technologies Used

- **Database:** SQL Server
- **Programming:** T-SQL
- **ETL:** SSIS
- **Data Warehousing:** Star Schema, Dimensional Modeling
- **Business Intelligence:** Power BI
- **Analytics:** DAX, SQL
- **Reporting:** Power BI Dashboards

## ⚙️ ETL Process

The SSIS ETL workflow includes:

1. Extracting data from source systems
2. Loading data into staging tables
3. Data cleansing and validation
4. Data transformation
5. Loading dimension tables
6. Loading fact tables
7. Applying business rules
8. Validating warehouse data

## 🗄️ Data Warehouse
